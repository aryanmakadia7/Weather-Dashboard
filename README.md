🌦️ Weather Dashboard

## 🚀 Live Demo

[Open Weather Dashboard](https://vercel.com/aryanmakadia7/weather-dashboard/7UUzMgDehbtTotPZyZwrgkFCuC2E)

A responsive Weather Dashboard built using HTML, CSS, and JavaScript. The project uses a weather API to display real-time weather information for different cities.

⚙️ How to Run
Download or clone this repository.
Open the project folder.
Open index.html in a web browser.
Enter a city name in the search box.
Click Search to view the weather information.
🔑 API Key

This project requires a weather API key to retrieve weather information.

Before uploading the project to a public GitHub repository, make sure your personal API key is not exposed in the code.

📱 Responsive Design

The dashboard is designed to work on:

💻 Desktop
💻 Laptop
📱 Mobile
📱 Tablet

The layout automatically adjusts according to the screen size.

🎯 Project Objective

The main objective of this project is to develop an interactive frontend application that can retrieve and display real-time weather information using an API. It also demonstrates the use of JavaScript, API integration, responsive web design, and dynamic webpage updates.
